# Maltese (mt)
* Maltese combines a Semitic (root-and-pattern) layer with a Romance (Italian/Sicilian) layer
* the definite article and fused prepositions are hyphenated proclitics (il-ktieb, tal-iskola) and are split off by pre-tokenization, so they need no rules
* broken plurals (ktieb : kotba, dar : djar, belt : bliet) are non-concatenative and give separate stems
* templatic verb stem alternations (kiteb : kitbet : ktibt) give separate stems
* imperfect prefix forms (nikteb, tikteb, jikteb) are zero-suffixed and become their own stems; only their plural -u is covered
* derived Semitic verb forms (kiteb : kitteb : tkiteb) give separate stems
* the elative (kbir : akbar) is templatic; comparison is usually analytic (iktar sabiħ) and needs no rules
* stacked object/dative clitics (qaltilhom, bagħathieli) are not covered; only the basic possessive set is

## adjectives
* broken adjective plurals (sabiħ : sbieħ, kbir : kbar) give separate stems

### agreement

```
feminine: sabiħ-a modern-a
plural:   modern-i malt-in
```

### romance classes

```
common: elettroni-ku elettroni-ka elettroni-ċi
        perikol-uż perikol-uża perikol-użi
```

## nouns
* Maltese has no case system; nouns inflect for number only

### sound plurals

```
-i:       kart-i lingw-i karozz-i
-iet/-at: xitw-iet ġimgħ-at triq-at
-ijiet:   post-ijiet xogħl-ijiet omm-ijiet
-ajiet:   attivit-ajiet universit-ajiet
-a/-in:   ħaddiem-a miktub-in maħbub-in
```

### dual

```
common: jum-ejn xahr-ejn id-ejn
        sen-tejn sagħ-tejn
```

### possessive suffixes

```
common: missier-i missier-ek missier-u missier-ha
        missier-na missier-kom missier-hom
        omm-i omm-na
```
